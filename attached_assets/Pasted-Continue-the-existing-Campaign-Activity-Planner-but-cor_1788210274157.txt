WEBINAR SCHEDULE ENGINE

Store schedule rules as configurable data, not hard-coded UI logic.

Initial default template:

Recruitment track:
- Invitation 1: D-21 at 10:00 audience-local time
- Invitation 2: D-14 at 10:00
- Invitation 3: D-7 at 10:00
- Final invitation: D-1 at 10:00

Registrant track:
- Confirmation: immediately after registration
- Reminder: 24 hours before the webinar
- Reminder: 30 minutes before the webinar
- Optional “Starting now” reminder at event start

Post-event branching:
- Attended → Thank-you email on the next business day
- Did not attend → Sorry-we-missed-you email on the next business day
- Optional replay/nurture email at D+7
- Optional explicit handraiser CTA for attendees and/or no-shows

Business-date behavior:
- If a pre-event communication lands on Saturday, Sunday, or a configured holiday, move it backward to the preceding valid business day
- Never shift a pre-event communication later unless a user explicitly overrides it
- For post-event communication, shift forward to the next business day
- Store both the calculated date and any manual override
- Record the reason for every adjustment

Registration suppresses all remaining recruitment invitations.

Attendance must branch recipients into attendee and no-show tracks.

Attendance by itself is not a handraiser signal. A handraiser requires an explicit action such as requesting contact, a consultation, a demo, or more information.

CODES AND UTM

Generate codes through Governance for every campaign, webinar activity, communication, and tracked link.

Each record must have:

- Stable application UUID
- Governance record ID
- Human-readable governed code
- Code status
- Last synchronized timestamp

Create UTM values centrally rather than typing them independently into emails.

Example mapping:

- utm_source = approved delivery source
- utm_medium = email
- utm_campaign = governed campaign code
- utm_content = governed communication code
- utm_term = approved audience/cohort code when permitted

Never include names, email addresses, Salesforce IDs, or other personally identifiable data in UTM values.

Create a link registry so the final tracked URL is generated from:

base destination URL + governed UTM values
